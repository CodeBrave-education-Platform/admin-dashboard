# Specification Report: Question Schema & Data Models

## Executive Summary
This document provides an exhaustive, authoritative specification of all question schemas, data models, question formats, field requirements, and structured JSON output formats across the **ASENTRA Admin Dashboard** and **CodeBrave Education Platform CBT Engine**.

This specification directly guides the Gemini AI PDF Parser (`@google/genai`) to produce structured JSON payloads that seamlessly integrate with `UniversalPdfImporterModal.jsx`, `QuestionBankClient.jsx`, `TestCompiler.jsx`, `CbtEngineClient.jsx`, and the underlying Supabase database tables (`test_questions`, `test_exams`, `questions`).

---

## 1. Supported Question Formats & Architectural Models

The platform supports **5 primary question formats** conforming to National Testing Agency (NTA), JEE Main/Advanced, NEET, and CBSE exam standards:

| Format Identifier (`formatType`) | UI / Legacy Alias | Question Style | Options Structure | Answer Representation | Typical Marking Scheme |
|---|---|---|---|---|---|
| `single_mcq` | `single` | Single Choice Multiple Choice | Array of exactly 4 strings: `[optA, optB, optC, optD]` | `correct_option_index`: `0..3`<br>`correct_answer`: string of option | `+4` positive, `-1` negative |
| `multi_mcq` | `multiple` | Multiple Choice Multi-Correct | Array of 4 strings: `[optA, optB, optC, optD]` | `correct_option_index`: array of indices `[0, 2]` or primary index<br>`correct_answer`: string (e.g. `"Option A, Option C"`) | `+4` positive, `-2` or `-1` negative |
| `matrix_match` | `match` | Matrix Match / Column Matching | Array of 4 mapped option strings (e.g. `["A->P, B->R, C->S, D->Q", ...]`) | `correct_option_index`: `0..3`<br>`correct_answer`: string of correct mapping | `+4` positive, `-1` negative |
| `assertion_reason` | `assertion_reason` | Assertion & Reasoning | Array of 4 standard NTA A/R evaluation statements | `correct_option_index`: `0..3`<br>`correct_answer`: option string | `+4` positive, `-1` negative |
| `numerical` | `integer` | Numerical / Integer Input | Empty array `[]` | `correct_option_index`: `0` (or `null`)<br>`correct_answer`: numerical string (e.g. `"42"`, `"-890.4"`) | `+4` positive, `0` negative |

## 2. Comprehensive Field-by-Field Specification

Every question object generated by the Gemini parser and handled by the application contains the following fields:

### Core Identity & Classification
1. **`id`** (`string`, Required)
   - Unique identifier for the question.
   - Format: `pdf-q-${index}-${timestamp}` (e.g. `"pdf-q-1-1771165800000"`).
   - Used for React keying, selection tracking, and database primary keys.

2. **`subject`** (`string`, Required)
   - Academic subject domain.
   - Canonical enum: `"Physics"`, `"Chemistry"`, `"Mathematics"`, `"Biology"`, `"Computer Science"`, `"General"`.
   - Preserves standard capitalization.

3. **`sub_topic`** / **`topic`** (`string`, Required)
   - Specific chapter or conceptual topic (e.g., `"Rotational Dynamics"`, `"Chemical Bonding"`, `"Limits & Calculus"`, `"Human Physiology"`, `"Number System"`).
   - Fallback if unidentified: `"General"`.

4. **`difficulty`** (`string`, Required)
   - Difficulty level for adaptive testing and student analytics.
   - Canonical values: `"EASY"`, `"MEDIUM"`, `"HARD"`.

5. **`section`** (`string`, Optional)
   - Test section categorization (e.g., `"Section A"`, `"Section B"`, `"PYQ"`).
   - Default: `"Section A"`.

6. **`formatType`** (`string`, Required)
   - Canonical format identifier: `"single_mcq"`, `"multi_mcq"`, `"numerical"`, `"assertion_reason"`, `"matrix_match"`.

### Question Body & Visual Media
7. **`content`** / **`questionText`** (`string`, Required)
   - The primary question stem / problem statement.
   - Supports Markdown formatting and LaTeX mathematical equations.
   - Math notation delimiters:
     - Inline equations: `$ ... $` (e.g., `$\\lim_{x \\to 0} \\frac{\\sin(3x)}{x}$`)
     - Display / Block equations: `$$ ... $$` (e.g., `$$\\int_0^{\\pi} \\sin(x) dx$$`)
   - Auto-rendered in frontend via `KatexRenderer.jsx`.

8. **`diagram_url`** / **`diagramUrl`** (`string`, Optional)
   - URL to an associated diagram, schematic, circuit, graph, or visual asset.
   - If no diagram is present in the source PDF: `""` (empty string).

### Options & Solution Mechanics
9. **`options`** (`string[]`, Required)
   - Array of option text strings.
   - For `single_mcq`, `multi_mcq`, `assertion_reason`, `matrix_match`: Must contain exactly **4 strings** corresponding to Option A, B, C, D (or 1, 2, 3, 4).
   - Redundant prefixes (e.g. `"(A)"`, `"A."`, `"(1)"`) must be stripped from the option content itself.
   - For `numerical`: Must be an empty array `[]`.

10. **`correct_option_index`** (`integer` or `integer[]`, Required)
    - 0-based integer index corresponding to the correct option:
      - `0` = Option A (or 1st option)
      - `1` = Option B (or 2nd option)
      - `2` = Option C (or 3rd option)
      - `3` = Option D (or 4th option)
    - For `multi_mcq`: Array of 0-based indices (e.g., `[0, 2]`) or primary index `0`.
    - For `numerical`: `0` (or `null`).

11. **`correct_answer`** / **`correctAnswer`** (`string`, Required)
    - Verbatim string value of the correct answer.
    - For MCQs: Text of the correct option (e.g., `"503800702"`, `"Adolescence"`, `"-4"`).
    - For Numerical: Exact numerical string (e.g., `"42"`, `"-3.14"`).
    - For Matrix: Mapping string (e.g., `"A->P, B->R, C->S, D->Q"`).

12. **`explanation`** / **`solution_explanation`** (`string`, Required)
    - Step-by-step mathematical derivation, chemical equation, or conceptual reasoning explaining how the answer is obtained.
    - Supports LaTeX mathematical formulas with `$` and `$$` delimiters.

13. **`marks`** (`object`, Optional)
    - Scoring scheme for this specific question:
      - `positive`: Integer positive marks awarded on correct answer (default: `4`).
      - `negative`: Integer negative penalty deducted on incorrect answer (default: `-1` for MCQ, `0` for Numerical).

14. **`selected`** (`boolean`, UI state)
    - Initialized to `true` on the frontend review modal so all extracted questions are pre-checked for ingestion.

## 3. Detailed Specifications by Question Format

### 3.1 Single Choice MCQ (`single_mcq`)
- **Structure**:
  ```json
  {
    "id": "pdf-q-1-1771165800001",
    "subject": "Physics",
    "sub_topic": "Rotational Dynamics",
    "difficulty": "HARD",
    "formatType": "single_mcq",
    "content": "A solid sphere of mass $M$ and radius $R$ rolls down an inclined plane of angle $\\theta$ without slipping. The acceleration of its center of mass is:",
    "diagram_url": "",
    "options": [
      "\\frac{5}{7} g \\sin \\theta",
      "\\frac{2}{5} g \\sin \\theta",
      "\\frac{3}{5} g \\sin \\theta",
      "\\frac{1}{2} g \\sin \\theta"
    ],
    "correct_option_index": 0,
    "correct_answer": "\\frac{5}{7} g \\sin \\theta",
    "explanation": "For rolling without slipping: $a = \\frac{g \\sin \\theta}{1 + I/(MR^2)}$. For solid sphere, $I = \\frac{2}{5}MR^2$. Therefore, $a = \\frac{g \\sin \\theta}{1 + 2/5} = \\frac{5}{7} g \\sin \\theta$.",
    "marks": { "positive": 4, "negative": -1 }
  }
  ```

### 3.2 Multiple Choice Multi-Correct (`multi_mcq`)
- **Structure**:
  ```json
  {
    "id": "pdf-q-2-1771165800002",

    "formatType": "multi_mcq",
    "content": "Which of the following complexes is/are diamagnetic and square planar? (One or more than one correct)",
    "diagram_url": "",
    "options": [
      "[Ni(CN)_4]^{2-}",
      "[PtCl_4]^{2-}",
      "[NiCl_4]^{2-}",
      "[Co(NH_3)_6]^{3+}"
    ],
    "correct_option_index": 0,
    "correct_answer": "[Ni(CN)_4]^{2-}, [PtCl_4]^{2-}",
    "explanation": "Both $[Ni(CN)_4]^{2-}$ and $[PtCl_4]^{2-}$ have $d^8$ electron configuration with strong field ligands, resulting in $dsp^2$ hybridization and diamagnetic square planar geometry.",
    "marks": { "positive": 4, "negative": -2 }
  }
  ```

### 3.3 Numerical / Integer Input (`numerical`)
- **Structure**:
  ```json
  {
    "id": "pdf-q-3-1771165800003",
    "subject": "Mathematics",
    "sub_topic": "Definite Integration",
    "difficulty": "MEDIUM",
    "formatType": "numerical",
    "content": "Evaluate the integral: $I = \\int_0^1 (1 - x^2)^3 dx$. The value of $105 \\times I$ is equal to:",
    "diagram_url": "",
    "options": [],
    "correct_option_index": 0,
    "correct_answer": "48",
    "explanation": "Expanding: $(1 - x^2)^3 = 1 - 3x^2 + 3x^4 - x^6$. $I = [x - x^3 + \\frac{3}{5}x^5 - \\frac{1}{7}x^7]_0^1 = 1 - 1 + \\frac{3}{5} - \\frac{1}{7} = \\frac{16}{35}$. Thus, $105 \\times I = 105 \\times \\frac{16}{35} = 48$.",
    "marks": { "positive": 4, "negative": 0 }
  }
  ```

### 3.4 Matrix Match / Column Matching (`matrix_match`)
- **Structure**:
  ```json
  {
    "id": "pdf-q-4-1771165800004",

      "A->R, B->Q, C->S, D->P",
  ```

## 6. Discovered Features & Edge Cases

### Features Discovered
| # | Category | Feature | Description | Inputs | Outputs | Error Behavior | Discovered Via |
|---|---|---|---|---|---|---|---|
| 1 | Math Rendering | KaTeX LaTeX Engine | Renders inline (`$...$`) and block (`$$...$$`) math formulas in question stems and options. | LaTeX strings with `\\lim`, `\\frac`, `\\int`, etc. | KaTeX HTML DOM elements | Returns formatted text on syntax error | `KatexRenderer.jsx` |
| 2 | Subject Taxonomy | 5-Domain Subject Classifier | Categorizes questions into Physics, Chemistry, Mathematics, Biology, Computer Science. | Question text, options, explanation | Capitalized Subject string | Defaults to "General" or "Mathematics" | `parse-pdf/route.js:68` |
| 3 | Question Types | 5 Supported Question Types | Single MCQ, Multi-Correct MCQ, Numerical, Assertion-Reason, Matrix Match. | Question stem, options list, answers | Typed Question Object with `formatType` | Fallback to `single_mcq` | `QuestionBankClient.jsx`, `TestCompiler.jsx` |
| 4 | Visual Attachments | Diagram Image Preview | Attaches image diagram URLs to question stems with real-time rendering in modals and CBT player. | Diagram URL string | Image tag / Next Image component | Renders empty if `""` | `UniversalPdfImporterModal.jsx:420` |
| 5 | Review & Selection | Selective Ingestion Studio | Interactive review interface allowing admins to select, edit, KaTeX-preview, and ingest questions. | `parsedQuestions` array | Ingested question array dispatched to target module | Alerts if 0 selected | `UniversalPdfImporterModal.jsx:216` |
| 6 | CBT Exam Engine | Offline-Resilient CBT Player | Runs real-time timed CBT tests with KaTeX rendering, calculator, scratchpad, and server-side grading. | `test_exams.questions` JSONB | Attempt score, accuracy, XP gamification | Fails gracefully to memory state if offline | `CbtEngineClient.jsx`, `grade/route.js` |

### Edge Cases Handled
| # | Feature | Input | Observed / Expected Behavior |
|---|---|---|---|
| 1 | Matrix Match | Complex Column I (A-D) to Column II (P-S) mapping | Options represent combination codes (`A->P, B->R, C->S, D->Q`); `correct_option_index` matches the correct combination index. |
| 2 | Assertion-Reason | Assertion and Reason formatted with (A) and (R) | Stem captures both statements; options standard 4-statement evaluation list. |
| 3 | Numerical / Integer | Free-form numbers like `42`, `-890.4`, `5.25` | `options` is `[]`; `correct_answer` stores exact string; `marks.negative` defaults to `0`. |
| 4 | Multi-Correct MCQ | Multiple correct answers (e.g. A and C) | `correct_option_index` contains primary index `0` or array `[0, 2]`; `correct_answer` contains comma-separated names. |
| 5 | LaTeX Brackets | Chemical formulas with brackets e.g. `[Ni(CN)4]2-` | Protected from delimiter corruption; rendered smoothly via KaTeX. |
| 6 | Missing Diagram | Question without diagram image | `diagram_url` is `""`; UI gracefully hides diagram container without layout shift. |

## 2. Interface Conformance & Schema Verification

### 2.1 Question Schema Support (5 Formats)

The question objects generated by the backend and transformed by `UniversalPdfImporterModal.jsx` were verified against the schemas required by all downstream consumers:

| Format Type (`formatType`) | Option Structure | `correct_option_index` | `correct_answer` | Downstream Compatibility |
|---|---|:---:|---|:---:|
| `single_mcq` | Exactly 4 clean strings | `0..3` | Option string matching index | ✅ Verified (`QuestionBankClient`, `CompilerClient`, `TestCompiler`) |
| `multi_mcq` | Array of strings | Primary index (`0..3`) | Comma-separated or combined answer | ✅ Verified (`marks.negative = -2` preserved) |
| `numerical` | Guaranteed empty array `[]` | `0` | Signed numerical value (e.g. `"-5"`, `"24.5"`) | ✅ Verified (`marks.negative = 0` preserved) |
| `assertion_reason` | Exactly 4 evaluation options | `0..3` | Selected assertion/reason evaluation | ✅ Verified (4-option standard NTA structure) |
| `matrix_match` | Exactly 4 mapping combinations | `0..3` | Column mapping (e.g. `"A->R, B->Q, C->S, D->P"`) | ✅ Verified (Column I/II mapping preserved) |

### 2.2 Dual-Property Alias Safety

`UniversalPdfImporterModal.jsx` provides seamless backward and forward compatibility by normalizing question objects with dual aliases before invoking `onConfirmIngest`:
- `content` ↔ `questionText`
- `diagram_url` ↔ `diagramUrl`
- `correct_answer` ↔ `correctAnswer`
- `sub_topic` ↔ `topic`

This guarantees zero data loss or undefined field errors regardless of whether the consumer expects snake_case (`route.js` / Gemini standard) or camelCase (`QuestionBankClient` standard).

## 3. KaTeX Formatting & Mathematical Rendering Safety

The KaTeX rendering pipeline was evaluated in `src/components/KatexRenderer.jsx` and the modal preview grid:

1. **Delimited Formula Parsing**: Correctly splits and renders `$inline$` and `$$block$$` formulas as well as `\(...\)` and `\[...\]` delimiters.
2. **Chemical & Bracket Protection**: Square bracket notations (e.g. `[Ni(CN)4]2-`, `[Co(NH3)6]3+`, interval `[0, 3]`) and negative signed numbers (`-5`, `-1`) do not break parser logic or throw exceptions.
3. **Graceful Fallback**: `throwOnError: false` is configured on `katex.renderToString()`, wrapped with `try / catch` blocks. If an invalid or unparseable LaTeX snippet is encountered, it renders the raw text span without crashing the React component tree.
4. **Auto-Beautification**: Plain text math expressions like `lim (x->0)`, `dy/dx`, `ln |x|`, `x^(2)` are safely transformed into standard LaTeX before rendering.

## 4. Adversarial Challenges & Stress Testing

### Challenge 1: Unrecognized or Malformed `formatType`
- **Scenario**: LLM returns an unconventional formatType like `"single"` or `"matrix"` or undefined string.
- **Handling**: `sanitizeGeminiQuestions` in `route.js` normalizes aliases (`single` → `single_mcq`, `integer` → `numerical`, `match` → `matrix_match`, etc.) and safely falls back to `'single_mcq'`.
- **Result**: **PASS**

### Challenge 2: Option Array Boundary Conditions
- **Scenario**: Document or AI output returns fewer than 4 options (e.g. True/False question) for an MCQ.
- **Handling**: Backend and modal pad remaining options with `'Option C'`, `'Option D'` to prevent out-of-bounds index errors in downstream rendering.
- **Result**: **PASS**

### Challenge 3: Redundant Option Label Pollution
- **Scenario**: Extracted options retain redundant leading markers like `(A) Option text`, `[B] text`, `1. text`, `C: text`.
- **Handling**: Sanitizer regex `^[\(\[]?\s*[A-Da-d1-4]\s*[\)\]\.\-\:]\s+` strips redundant prefixes, ensuring clean option text in KaTeX renderer.
- **Result**: **PASS**

### Challenge 4: Zero-Cost Deterministic Fallback on Gemini Failure
- **Scenario**: Network timeout, Gemini API 503 Overloaded, or missing `GEMINI_API_KEY`.
- **Handling**: Route catches errors gracefully and immediately falls back to `parseExtractedText` deterministic regex engine if `rawText` is present, returning HTTP 200 with `parserType: 'deterministic_engine'`. If no text is available, returns structured JSON `{ success: false, error: ... }` with HTTP 500.
- **Result**: **PASS**
